# AI Sentiment Analyzer

A beginner-friendly Natural Language Processing (NLP) project that classifies short customer messages as **positive** or **negative**.

## What it demonstrates
- Text preprocessing with TF-IDF vectorization
- Supervised machine learning with Logistic Regression
- Prediction confidence for new messages
- A simple, reproducible training dataset

## Tech stack
Python · scikit-learn · NLP · Logistic Regression

## Run locally

```bash
pip install -r requirements.txt
python app.py
```

The script trains a model and prints sentiment predictions for example customer feedback.

## Example use cases
- Review monitoring
- Customer-support feedback analysis
- Social-media sentiment triage
